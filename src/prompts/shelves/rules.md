Keep: how the user wants every agent to work with them, as the user put it: what they say to do "always", "never" or "from now on", and corrections they expect to hold in later sessions too.
Leave out: what the agent decided by itself; a request about the task at hand ("skip the tests this time"); a rule for one project only, which is a fact about that project.
Write it as an instruction to an agent, with its condition when it has one.
Good: "Reply in Chinese; keep code, comments and commit messages in English."
Not this: "The user prefers Chinese." (a report about the user, not an instruction)
