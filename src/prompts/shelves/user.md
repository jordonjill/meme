Keep: lasting facts about the user and their machines that an agent would otherwise have to ask or find out again: the systems they work on and how those are set up, where their tools are, what they work on and in what role, the languages they read.
Leave out: names, e-mail addresses, account names and other identifiers; what holds only today; personal matters that have nothing to do with the work.
Write it as a fact about the user, in the present tense.
Good: "Develops on macOS and in a Linux virtual machine; Node versions are managed with nvm."
Not this: "Commits as Alex <alex@example.com>." (an identifier)
